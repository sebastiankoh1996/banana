# Banana reading workspace

Approved 30 October 2026; user authorized implementation and publication.

Mode: Operate / Read. PRODUCT.md remains the behavior specification.

Use Segoe UI with Arial/system sans fallbacks for headings and controls, existing CJK sans stack for reading. Medium is 28px desktop and 26px at widths up to 700px; preserve Small/Large. Day: white reading surface and pale gray tools rail. Night: neutral charcoal surfaces with light text. Yellow marks primary action and selected preferences. Controls use consistent 7–8px corners, thin neutral rules, and visible focus outlines.

Desktop: compact header with banana mark, countdown, day/night toggle; 224px tools rail; reading heading with Copy/Undo; reading sheet with attached Play/Pause/Stop and scope label. Mobile stacks tools above the reading sheet. No Your text heading. No audio timeline, seeking, volume, speed selection, fake metrics, or demonstration text injected into user documents.

Preserve existing IDs and JS behavior, origin and localStorage keys banana.text / banana-night-mode. Preserve loading GIF, warning/alarm animation including timer growth, and license files. UI overrides are in workbench.css; retain redesign.css and existing resources.
